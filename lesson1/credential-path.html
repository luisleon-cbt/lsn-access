Things to notice

  • The reader only reads. The controller decides with data it already stores, so the door keeps working when the PC is off.
  • On Wiegand the number crosses the cable as plain bits. A secure smart card or phone does not help much if the reader then talks Wiegand.
  • Parity bits only catch noise and wiring errors. They are not security: anyone can compute them, as this page does.
  • A 125 kHz proximity card always sends the same number with no secret key, so it is easy to clone. Upgrades usually move to 13.56 MHz smart cards or mobile credentials.
  • OSDP Secure Channel encrypts reader traffic with AES-128, and the controller polls the reader all the time, so a cut cable or a swapped reader raises an alarm.
